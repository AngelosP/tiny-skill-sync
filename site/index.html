Keep your Copilot skills in sync with GitHub

Tiny Skill Sync is a tiny Windows tray app. Tell it which GitHub repositories, or which folder of one, hold skills. It installs them into your Copilot skills folder, checks GitHub on a schedule, and installs, updates and removes skills as they change there.

It never touches a skill it did not install, and it never overwrites or deletes a skill you edited. It removes from your PC only what came from GitHub and was later removed there.

Download the latest release See it on GitHub

Windows 10 and 11, x64. No installer and no runtime: unzip it and start it. The exes are not signed.

What it does

  • Small and quiet

    One exe of about 1 MiB, with no runtime to install. It starts in about 8 ms, uses about 1 MiB of memory while idle, and does no work at all between checks: no CPU, no disk, no network.

  • Starts with Windows, without slowing it down

    At sign-in it goes straight to the tray and waits 30 seconds before it looks at your skills or checks GitHub, then does both at low priority. It asks before it turns this on.

  • Cheap checks

    An unchanged repository costs one small "has anything changed?" request to GitHub, which reads and writes no files.

  • Public and private repositories

    Public ones need nothing. Private ones are read with your GitHub CLI sign-in (gh auth login) or a token saved in Windows Credential Manager.

  • A tray icon and a window

    See every repository and skill, what needs you in plain words, and line by line what is different between GitHub and your copy. It follows the Windows light or dark mode.

  • A command line too

    tss does the same work, one command at a time.

Safety promises

Your skills folder holds work you care about. These are the rules the app follows, and each one is covered by tests.

  1. What you add is yours

    The app takes over a skill folder it did not install only when that folder holds every file of one version from GitHub, unchanged. Files you add inside a skill are never changed, deleted or even shown, and they stay when the skill is updated or removed.

  2. Your edits win

    If you change or delete a file the app installed and the skill changes on GitHub too, the app changes nothing and asks you what to do. If you delete a whole skill, it stays deleted unless you ask for it back.

  3. A failure is never a deletion

    No network, a wrong token, a missing repository or a strange answer from GitHub only means "could not check". Skills are removed only when GitHub's complete listing says they are gone. If a repository suddenly lists no skills at all, nothing is deleted until you confirm.

  4. Nothing is lost

    A skill is downloaded and checked in full before it replaces the old one. If the app or the PC stops half way, the next start finishes or undoes the change. Anything set aside is kept as a backup and never deleted.

  5. Edits made while it was off are found

    The app records what each file it installs looks like, so an edit made while it was not running is still found, even one that keeps the file's size and times. Before any update or removal it reads every file again.

  6. Downloads are never run

    Skills often contain scripts. The app only copies them.

The user guide explains each rule in full.

Get started

  1. Download tiny-skill-sync-VERSION-windows-x64.zip from the latest release. SHA256SUMS.txt next to it holds the SHA-256 of the zip and of both exes. Or let the GitHub CLI fetch it:

    gh release download --repo AngelosP/tiny-skill-sync --pattern *

  2. Unzip it into a folder of your choice, for example %LOCALAPPDATA%\Programs\tiny-skill-sync, and start tiny-skill-sync.exe. Its icon, a blue tile with two sync arrows round a spark, appears in the notification area. The exes are not signed, so Windows may ask before the first start: choose More info, then Run anyway.

  3. Click the icon to open the window. Click Add repository, paste the address of a GitHub folder that holds skills, and click Add. For example:

    https://github.com/anthropics/skills/tree/main/skills

  4. The app installs the skills at once, then checks once a day. It also asks whether to start with Windows.

To update, quit the app (right-click the icon, then Quit), replace both exes with the new ones and start it again. Your settings stay in %LOCALAPPDATA%\tiny-skill-sync.
